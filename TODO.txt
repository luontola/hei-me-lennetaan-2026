Before publishing
=================

Hosting
- [ ] Add a GitHub Actions workflow (.github/workflows/pages.yml) that publishes the site/ directory.
      GitHub Pages "Deploy from a branch" can only serve / or /docs, not site/.
- [ ] In the repository settings, set Pages > Source to "GitHub Actions".
- [ ] Use a custom domain.

Content (site/config.js)
- [ ] Set the title of each game.
- [ ] Set the game mode ("pelimuoto"), level ("taso") and description of each game.
- [ ] Add an image for each game (e.g. site/assets/games/game-1.webp) and set "image" in the config.
- [ ] Check the intro text in site/index.html.

Google Form
- [ ] Rename the "Peli" options to the real game names.
      Each option text must be exactly the same as "formOption" in site/config.js,
      or the prefill does not select the game and the scores do not show on the site.
- [ ] Decide about the screenshot upload field. A file upload forces every player to log in to Google.
- [ ] Do NOT turn on "Collect email addresses". Anyone with the link can read the responses sheet.
- [ ] If a question is renamed, update CONFIG.sheet.columns in site/config.js.
      If a field is replaced, get its new entry ID with "Get pre-filled link" and update CONFIG.form.
- [ ] After submit, link back to the site.

Google Sheet
- [x] Add the header "Hylätty" in the first empty column to the right of the form columns.
      Rows with any text in that column are hidden from the leaderboards.
- [ ] Keep the sheet shared as "Anyone with the link: Viewer".
- [ ] Delete the test rows (e.g. "Test, Peli 1, 123").

Testing (run ./dev-server.sh; file:// does not work)
- [ ] Name dialog: enter a name, check that the form opens in a new tab with the name and game prefilled.
- [ ] Check that the new tab is not blocked as a popup on iPhone Safari and Android Chrome.
- [ ] Submit a score, return to the site, check that the leaderboard updates and your row is highlighted.
- [ ] Add more than 5 players to one game, check the "⋯ + your own row" view and "Näytä kaikki".
- [ ] Logout and login with another name.
- [ ] Mark a row as rejected in the "Hylätty" column and check that it disappears.
- [ ] Test on a real phone.
